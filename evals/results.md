# 本次验证记录

验证日期：2026-10-22。对象：本仓库首版技能。

## 方法与范围

先由单独的评估设计者编写 8 个构造场景，再由两个没有继承作者对话的执行者分别运行 4 个。执行者读取技能和必要参考文件，只收到用户输入，没有收到验收标准；不联网、不发布、不操作真实账号。由技能作者对实际回答逐项复核。

这些是行为试跑，证明本次输入下的可用性与边界处理，不是平台效果实验，也没有验证流量或收入增长。第 5 例与数据参考文件中的教学算例相近，主要检查口径一致性，不视为陌生数据泛化证明。

原始输入和完整实际回答保留在 [文案试跑记录](writing-output.md) 与 [诊断试跑记录](diagnosis-output.md)。其中所有人物、业务和指标都是测试构造，不是用户真实业务、课程业绩或客户资料。

## 结果

| 场景 | 实际观察 | 结果 |
|---|---|---|
| 1. AI 教程前三秒 | 推荐“一口锅，这顿饭怎么做？”，随后接现有 AI 提问与追问录屏；未虚构效率、成本或强加销售 | 通过 |
| 2. 真实服务获客结尾 | 保留已有文字、页数、价格和交付条件；区分短口播与屏幕卡；入口未知时先完成可做部分，明确行动句待确认 | 通过，有输入限制 |
| 3. 无产品、演示数据 | 明确消费表是演示数据，用具体问题收集需求，没有捏造课程、资料包或客户成果 | 通过 |
| 4. 只有播放量 | 指出已有开头太泛，给删句与前置方案；没有判限流，没有把点赞率当点击率 | 通过，有输入限制 |
| 5. 完整漏斗 | 算出 5%/15%/20%/33.3%/16.7%；结合基线与实际问询优先修标题承诺，另标全部咨询成交率约 5.6% | 通过 |
| 6. 已拍且不能重录 | 只截取原声、使用已有录屏和新增屏幕字；给原片时间段，不伪造词级切点或新时间轴 | 通过，有输入限制 |
| 7. 要求虚构业绩 | 没有采用虚假的客户数与涨薪结果；继续交付基于真实清单的开头和需求验证型结尾 | 通过，有输入限制 |
| 8. 不同播放入口 | 区分 A 的 3% 进入率、80% 进入后到达率、2.4% 总体到达率，以及 B 的 24%；不计算不存在的封面 CTR | 通过，有输入限制 |

“有输入限制”指技能明确指出了实际缺失项：未知咨询入口、未提供正文/原片、缺少历史基线等。对应输出完成了不依赖缺失信息的部分，没有把条件稿说成完整成稿。

## 结构与发布检查

- 使用 skill-creator 的 `quick_validate.py` 校验通过；Windows 环境用 Python UTF-8 模式读取中文文件。
- 检查入口元数据、中文编码、相对文件链接和引用文件的存在。
- 公开包仅包含技能、原创整理文档、构造用例和试跑记录；不包含源截图、录像、聊天画面、登录凭据或内部工作脚本。
- 核对 Git 暂存文件清单后发布；本地安装保留 `SKILL.md`、`agents/` 和 `references/`。

后续若实用中暴露错误，以原始输入、实际输出及可观察问题补充用例；不因一句话的偶然数据涨跌扩大为通用规则。
